# RxOnyx — اللاندنج بيج

صفحة واحدة ثابتة. **مافيش build ولا npm ولا أي خطوة تجهيز** — Hostinger
بيسحب الملفات زي ما هي وتشتغل على طول.

```
index.html   ← الصفحة كلها (HTML + CSS + اللوجو جواها)
```

---

## ⚙️ الربط بـHostinger (مرة واحدة)

### ① ارفعي المشروع على GitHub
ريبو جديد اسمه `rxonyx-landing` — **Public**.

> 🔴 **ماتحطيهاش في ريبو RxOnyx الخاص.** ده خاص وفيه وثائقك وأبحاثك وخططك،
> وربطه باستضافة معناه تعريضه. اللاندنج بيج مالهاش أي سر فتفضل لوحدها.

```bash
cd rxonyx-landing
git init
git add -A
git commit -m "أول نسخة من اللاندنج بيج"
git branch -M main
git remote add origin https://github.com/asarrehan/rxonyx-landing.git
git push -u origin main
```

### ② النشر التلقائي — اللي اتعمل فعلًا (3/9/2026)
صفحة GIT في hPanel بقت بتشتغل بربط حساب GitHub واحد بس بحساب Hostinger،
والحساب المربوط هناك مش حسابك — فالربط بيتم من الناحية التانية:
**GitHub Actions بيرفع الملفات لـHostinger عبر FTPS مع كل push.**

| الحتة | فين |
|---|---|
| الـworkflow | `.github/workflows/deploy.yml` (فرع `main` → `public_html`) |
| بيانات FTP | **أسرار الريبو** Settings → Secrets → `FTP_SERVER` · `FTP_USERNAME` · `FTP_PASSWORD` — مش في الكود أبدًا |
| حساب FTP | متعمول في hPanel → الموقع → Files → FTP Accounts (مستخدم مخصوص للنشر) |

المتابعة: تبويب **Actions** في الريبو — كل push بيظهر كتشغيلة، خضرا يعني اتنشر.

> الشهادة بتاعة FTP باسم Hostinger مش بالـIP، فالـworkflow شغّال `security: loose`:
> التشفير شغّال وفحص اسم الشهادة بس متعطّل — مقبول لصفحة ثابتة عامة.

## 📐 قواعد التحرير

الصفحة مكتوبة على نفس قواعد المنتج:

- **مافيش رقم من غير سبب.** لو هتضيفي رقم، لازم يكون متقاس فعلًا.
- **مافيش «زوّدنا مبيعاتك بنسبة كذا»** قبل ما يبقى فيه قياس حقيقي.
- **مافيش ذكر للاشتراك ولا سعره** على الصفحة.
- **مافيش اسم شخصي ولا ختم.**
