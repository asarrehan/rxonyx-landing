# RxOnyx — اللاندنج بيج

صفحة واحدة ثابتة. **مافيش build ولا npm ولا أي خطوة تجهيز** — Hostinger
بيسحب الملفات زي ما هي وتشتغل على طول.

```
index.html   ← الصفحة كلها (HTML + CSS + اللوجو جواها)
```

---

## ⚙️ الربط بـHostinger (مرة واحدة)

### ① ارفعي المشروع على GitHub
ريبو جديد اسمه `rxonyx-landing` — **Public**.

> 🔴 **ماتحطيهاش في ريبو RxOnyx الخاص.** ده خاص وفيه وثائقك وأبحاثك وخططك،
> وربطه باستضافة معناه تعريضه. اللاندنج بيج مالهاش أي سر فتفضل لوحدها.

```bash
cd rxonyx-landing
git init
git add -A
git commit -m "أول نسخة من اللاندنج بيج"
git branch -M main
git remote add origin https://github.com/asarrehan/rxonyx-landing.git
git push -u origin main
```

### ② اربطيه في Hostinger
**hPanel → الموقع → متقدّم → GIT**

| الخانة | تحطي فيها |
|---|---|
| Repository | `https://github.com/asarrehan/rxonyx-landing.git` |
| Branch | `main` |
| Directory | **سيبيها فاضية** (يعني جذر `public_html`) |

ودوسي **Create**. بعد ثواني اكتبي الدومين في المتصفح وهتلاقيها شغّالة.

### ③ التحديث التلقائي — الخطوة اللي بتخلّيها أوتوماتيك
في نفس صفحة GIT في Hostinger هتلاقي **Auto-Deployment** ومعاه رابط
webhook. **انسخيه.**

بعدين في GitHub:
**الريبو → Settings → Webhooks → Add webhook**

| الخانة | القيمة |
|---|---|
| Payload URL | الرابط اللي نسختيه من Hostinger |
| Content type | `application/json` |
| Events | `Just the push event` |

**خلاص.** من دلوقتي أي `git push` بيحدّث الموقع لوحده في ثواني.

## 📐 قواعد التحرير

الصفحة مكتوبة على نفس قواعد المنتج:

- **مافيش رقم من غير سبب.** لو هتضيفي رقم، لازم يكون متقاس فعلًا.
- **مافيش «زوّدنا مبيعاتك بنسبة كذا»** قبل ما يبقى فيه قياس حقيقي.
- **مافيش ذكر للاشتراك ولا سعره** على الصفحة.
- **مافيش اسم شخصي ولا ختم.**
